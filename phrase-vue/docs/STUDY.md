# 行测学习 v2

这是个人、本地、离线优先的学习工具。默认备考目标为山西，可切换国考并筛选卷种。六个模块采用原卷标签，不自动推断细分题型，不生成课程、每日任务或间隔复习任务。

## 使用流程

1. 在「专项练习」选择目标、年份、模块、题量和出题顺序。随机题量不足时使用全部可用题目；顺序练习按年份由新到旧、原卷题序选取。选择后点「提交本题」查看反馈。可以跳题。
2. 在「真题套卷」选择原卷。训练时长默认为120分钟，可设置1–480分钟，不代表官方时限。可修改选项、标记待检查和通过答题卡跳题。交卷前隐藏答案；到时自动交卷。刷新或关闭浏览器不会暂停截止时间，再次打开后超时的会话会交卷。
3. 有草稿时先继续或明确放弃，避免覆盖未完成作答。放弃不生成成绩。首页、导航切换不会清除草稿。
4. 在「错题与笔记」筛选模块、来源和掌握状态，或查看收藏及纯文本笔记。答错的已核验题在交卷时入错题；未答、待核验和缺答案题不入错题。掌握状态由自己标记，掌握后再次答错会重新进入待复习。
5. 在「学习记录」查看成绩与逐题回顾，导出或恢复备份。换浏览器、换离线文件路径、清理网站数据前应先导出。

## 题库与判分口径

主库来自同级 `../fenbi/题库/`，包括山西10套1,230题、国考36套4,790题，总计46套6,020题。六模块为政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。原卷内容、题号、选项顺序及共用材料完整保留。

| 状态 | 数量 | 行为 |
| --- | ---: | --- |
| 已核验 | 3,497 | 与本地来源完整题干、选项内容及顺序、材料、答案比对一致，可自动判分 |
| 待核验 | 2,522 | 有参考答案，但图片依赖或文本、选项、材料不能可靠核对，不自动判分 |
| 缺答案 | 1 | 国考2022副省级第4题；保留题目和作答，不自动判分 |
| 缺解析 | 1,226 | 与上述状态重叠；显示“暂无解析” |

核验仅证明与缓存来源一致，不代表对题目事实或答案的权威认证。新库显示实际缓存来源，不笼统使用“官方解析”。图片、公式和图表题保留图片，共986个引用文件；点击图片可在面板中查看原图。

题目主键为 `试卷ID:原题号`。`qid`只作外部关联，同题跨卷不合并，套卷保持原题序及题量。原6,577题言语题源保留为独立扩展题源，默认不混入主库；沿用旧题源的一体化题干答案，支持旧错题重做。扩展题源默认加载最近三年，也可选单年。

成绩正确率为“答对数 / 全部可判分题数”，其中可判分的未答题计入分母；没有可判分题时显示“—”。模块与近期正确率为“已作答可判分题中的正确数 / 已作答可判分题数”。不推算官方分数。不同题数按稳定ID去重；重复练习增加作答次数，不增加已练不同题数。首页近期正确率使用最近10次完成的会话，按题目实际目标筛选。用时按完成会话累积，未完成草稿与已放弃会话不计入统计。旧汇总成绩不混入新统计。

另有11份旧山西PDF列在应用「学习记录」资料整理清单，首版未导入。原PDF与爬虫工程未修改。

## 存储、迁移与备份

IndexedDB数据库为 `xingce-learning` v1，`archive`对象仓库存储 `main`：一个版本2完整档案快照。内容包括目标、当前会话、完成会话、错题、收藏、笔记和旧汇总成绩。单个事务原子提交，排队写入，不按条数自动裁剪。主题继续使用 `vocab-theme`。

旧 `vocab-exam-history`、`vocab-exam-wrong` 在首次成功初始化时迁移；原键不删除。旧错题使用 `legacy:qid`，不猜测对应主库试卷。重复初始化不重复迁移。

导出格式为 `{format: "xingce-study-backup", exportedAt, data}`。恢复是替换，不是合并。恢复前校验版本、结构、稳定ID、全部题目引用、选项范围和当前阅读位置，重新计算已完成成绩；任何失败不覆盖原档案。导出包含草稿，但不包含题库或图片。

浏览器拒绝或无法读取IndexedDB时启用临时内存档案并显示提示，不覆盖原不可读档案。保存因配额等原因失败时，本次内存作答仍可导出，刷新后可能只能读取上一次成功提交。恢复备份必须真正完成数据库事务才算成功。

## 数据维护

```bash
npm run import:xingce                 # 从本地JSON与缓存重建，不访问网络
npm run import:xingce -- --check       # 只读比对全部生成物
npm run verify:xingce                 # 原资料、套卷、图片与保留内容校验
npm run verify:data
npm run verify:exam -- --strict
npm run verify:knowledge -- --strict
```

导入生成 `public/xingce/index.json`、按套卷JSON分片、引用图片，以及 `evidence/xingce-import.json` 异常清单。索引记录来源SHA-256；结果确定，不写入运行时间。禁止通过删题、删除图片或把顺序匹配当作已核验来提高覆盖率。

知识卡保持原859张，不替新增词条编造知识卡。实施期间有并行课程词库更新：899条变为1,037条、108组变为123组，共997个不同词名；新增138个词名尚无卡片。`evidence/refactor-vocab-before.json` 是按旧离线包还原的原899条词库，其SHA-256与任务启动基线一致。`verify:xingce`逐条证明旧内容、来源和相对顺序保留，并锁定新增后词库哈希。知识卡验证同时使用匹配原来源哈希的词库快照校验859张卡，另报告当前138个未覆盖词名，不宣称覆盖全部当前词库。

## 离线交付与边界

`offline/行测学习-离线版.html` 内嵌全部词汇、知识卡、主库、扩展题源、986张图片、字体、脚本和样式。主库按卷gzip，扩展题源按年gzip；图片只嵌入一次并按需创建Blob地址。构建要求小于64MiB。运行时无需Node、后端、CDN或网络；需要支持IndexedDB、DecompressionStream和现代ES模块的浏览器。

默认验证平台为本机macOS Chrome，桌面1440×1000与移动390×844视口。移动视口测试不代表iOS、Android实机验证。未验证Chromium90、UOS、Safari或其他旧浏览器。HTTP静态版按需加载题库，未实现PWA，不能承诺远程站点断网首次打开。

代码、组件许可与题目内容权利分开。原题源缺少明确再分发许可的既有限制继续保留；本交付仅用于本地个人学习，不包含发布服务或在线抓题。
