## 校订方式

- 在`../视频/成语校订/成语校订.json`中维护释义、日常用法、记忆技巧、适用语境、例句、关联词，保留来源及定位证据。
- 参考润色逐字稿与抽样课件，删除速记中不成立的绝对限制、固定程度排序；另对易错词联网查词典。具体28项重点更正及依据见同目录`校订说明.md`、`重点更正记录.json`。
- 每条新增例句都标为“【自拟例句】”。本次改写的释义、提示等不作为教师逐字原话。
- 全部522条至少有逐字稿精确词形及行号，或课件精确词形与抽样位置。锁定11份逐字稿与11份课件OCR的SHA-256；抽样时间不是授课起点。
- 原视频、原逐字稿和原HTML不改写；校订结果单独保存。未逐句回听整批录音，未对522条逐条联网查典。

## 导入和复查

从项目目录运行：

```bash
npm run import:video -- --check
npm run import:video
npm run verify:data
npm test
npm run build
npm run test:e2e
```

第一条只读核对底稿、输入哈希、每条本地依据、原515条内容和已导入结果。第二条重新生成词库、来源哈希、导入报告及可读校订稿；重复导入字节不变，不增加重复记录。第六条测试前需已有生产构建。

重新导入依赖同级`视频/成语校订`、`视频/逐字稿/润色逐字稿`、`视频/逐字稿/_work/ocr`。应用运行及普通测试不读取这些外部目录，不加载MP4。
