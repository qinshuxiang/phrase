# 精编规范（各讲共用）

本文件是逐字稿精编的唯一风格依据。每份稿子必须严格按本规范产出，不得自行调整结构。

## 一、允许与禁止

允许：

- 删掉口语填充词（啊、嗯、呃、这个、就是说、然后呢）与重复啰嗦。
- 把口语表达书面化，调整语序使句子完整。
- 按词条重组内容顺序，只要不改变教师原意。
- 合并同一词条在多处重复讲到的同一条要点。

禁止：

- 补充原文没有的释义、典故、出处、近义辨析维度、例句。
- 修改例句用词，或自造例句。
- 把教师的"个人提醒"升级成普适规律。
- 添加原文没有的评价、总结、学习建议。
- 写时间点、时间轴。

原文没讲但模板要求填的项，写「课上未展开」，不得推测填充。

## 二、判定标准

一句话写进稿子前，自问：这句话的意思，能否在原文中找到对应表述？

- 能逐句对应 → 可以写。
- 只能对应一半，另一半是自己补的 → 删掉补的部分。
- 完全对应不上 → 不写。

## 三、文件结构

```markdown
# {日期} {课型} 第{讲次}讲 · {教师}

> 课程：{课程全称}　|　讲次：{讲次}　|　教师：{教师}
> 源视频：{原文件名}（{时长}）
> 说明：本稿由课堂录音整理，按词条分节，非逐字记录。

## 本讲概览

- 覆盖范围：第 X–Y 组，共 N 个词条
- 本讲主线：一句话概括教师本次的讲解重点
- 最易混：A / B、C / D（只列教师明确强调过的）

## 第X组

### 词条名

- **核心义**：……
- **语义侧重**：……
- **感情色彩**：……
- **常见搭配**：……
- **课上例句**：……
- **易混**：与「某词」的差别在……
- **做题提醒**：……

## 课堂提醒

- 教师本次反复强调的判断顺序、排除方法、易错点。
```

细则：

- 二级标题只用于"本讲概览""组号""课堂提醒"三类；词条一律三级标题。
- 组号以教师当次口述为准，写作「第45组」。教师未报组号时，用「其他词条」归类，不自行编号。
- 每个词条小节下的条目按实际讲到的情况取舍，未讲到的整条省略，不要留空条目。
- 单条内容控制在 1–3 句，不写成分段议论文。
- 出现数字、专名、组号时，必须与原文写法一致。
- 全文简体中文，全角标点，不用 Markdown 表格，不用分隔线。

## 四、写法示例

原文（口语）：

> 呃，这个防患未然呢，它强调的是在事情发生之前就做好准备，那么未雨绸缪也是提前准备，但是未雨绸缪更强调具体的行动，就是我已经开始做了，防患未然偏重于是思想上、制度上的防范。

精编：

### 防患未然

- **核心义**：在事情发生之前就做好防范。
- **语义侧重**：偏重思想、制度层面的防范。
- **易混**：未雨绸缪同样指提前准备，但更强调已经付诸具体行动。
- **课上例句**：课上未展开。
- **做题提醒**：课上未展开。

（说明：上例中"课上未展开"是占位写法；实际稿子只在教师确实没讲该项时使用。）

## 五、交稿前自检

1. 每个三级标题都是教师讲过的词条，没有自行新增。
2. 每条「课上例句」都能在原文中逐字找到。
3. 没有出现原文之外的人名、书名、典故、数字。
4. 没有时间点、没有表格、没有分隔线。
5. 三级标题数量与骨架清单一致。
